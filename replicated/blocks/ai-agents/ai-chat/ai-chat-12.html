Why do my webhook deliveries keep retrying?

ReUI Pro retries whenever your endpoint answers with anything outside the 200 range, or takes longer than ten seconds to answer at all.

  1. 1Open the delivery log for the failing event and read the status ReUI Pro recorded against each attempt.
  2. 2Acknowledge inside ten seconds. Return the response first, then do the work in a background job.
  3. 3Check the signature step. A rejected signature answers with 400, which counts as a failure and starts the backoff again.
  4. 4Return 200 for events you mean to ignore, so they leave the queue instead of retrying for a day.

Every attempt carries the same event id, so the handler has to be safe to run twice.
