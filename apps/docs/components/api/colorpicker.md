## Props

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| as? | any | 'div' | The element or component this component should render as. |
| throttle? | number | 50 | Throttle time in ms for the color picker |
| disabled? | boolean | - | Disable the color picker |
| defaultValue? | string | '#FFFFFF' | The default value of the color picker |
| format? | 'hex' \| 'rgb' \| 'hsl' \| 'cmyk' \| 'lab' | 'hex' | Format of the color |
| size? | ColorPicker['variants']['size'] | 'md' |  |
| class? | any | - |  |
| ui? | ColorPicker['slots'] | - |  |
