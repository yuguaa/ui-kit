## Props

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| render? | React.ReactElement | - | 渲染为指定元素 |
| label? | string \| number | - | 徽标文本 |
| count? | number | - | 显示数字（kit 既有属性） |
| dot? | boolean | - | 圆点模式，不显示数字（kit 既有属性） |
| overflowCount? | number | - | 超出后显示 99+（kit 既有属性） |
| variant? | XBadgeVariant | - | 预设样式 |
| color? | XBadgeColor | - | 徽标颜色 |
| size? | XBadgeSize | - | 徽标尺寸 |
| square? | boolean | - | 等边距模式，宽度等于高度，适合只放图标或单字符 |
| icon? | XIconName | - | 图标名，显示在左侧 |
| leadingIcon? | XIconName | - | 左侧图标名 |
| trailingIcon? | XIconName | - | 右侧图标名 |
| avatar? | XAvatarProps | - | 左侧头像配置 |
| leading? | React.ReactNode | - | 徽标内容之前的内容 |
| trailing? | React.ReactNode | - | 徽标内容之后的内容 |
| ui? | XBadgeUi | - | 主题插槽类名 |
| children? | React.ReactNode | - |  |
