## Props

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| to? | string | - | 链接地址 |
| color? | XLinkColor | - | 颜色 |
| active? | boolean | - | 激活态 |
| inactiveClass? | string | - | 非激活态附加类名 |
| disabled? | boolean | - | 是否禁用 |
| render? | React.ReactElement | - | 渲染为指定元素 |
| ui? | XLinkUi | - | 主题插槽类名 |
| leading? | React.ReactNode | - | 前置图标 |
| trailing? | React.ReactNode | - | 后置图标 |
| children? | React.ReactNode | - |  |
