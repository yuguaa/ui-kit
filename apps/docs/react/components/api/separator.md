## Props

| 名称 | 类型 | 默认值 | 说明 |

| orientation? | XSeparatorOrientation | - | 方向 |
| decorative? | boolean | - | 纯装饰分割线，不渲染无障碍角色 |
| label? | string | - | 标签文字 |
| icon? | XIconName | - | 标签图标 |
| avatar? | XAvatarProps | - | 标签头像 |
| color? | XSeparatorColor | - | 语义色 |
| size? | XSeparatorSize | - | 边框粗细 |
| type? | XSeparatorType | - | 线条样式 |
| position? | XSeparatorPosition | - | 标签位置 |
| render? | React.ReactElement | - | 渲染为指定元素 |
| ui? | XSeparatorUi | - | 主题插槽类名 |
| children? | React.ReactNode | - |  |
