## Props

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| loading? | boolean | - | 是否显示骨架 |
| variant? | XSkeletonVariant | - | 形状 |
| width? | number \| string | - | 宽度（覆盖 variant 默认宽度） |
| height? | number \| string | - | 高度（覆盖 variant 默认高度） |
| render? | React.ReactElement | - | 渲染为指定元素 |
| ui? | XSkeletonUi | - | 主题插槽类名 |
| children? | React.ReactNode | - |  |
