## Props

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| size? | XFieldGroupSize | - | 尺寸（控制字段间距） |
| orientation? | XFieldGroupOrientation | - | 排列方向 |
| inline? | boolean | - | 旧属性：true 等价 orientation="horizontal"，false 等价 vertical |
| render? | React.ReactElement | - | 渲染为指定元素 |
| ui? | XFieldGroupUi | - | 主题插槽类名 |
| children? | React.ReactNode | - |  |
